# JUNCTION v6 — 比較できる物を一切見せない(2026-09-03)

`docs/V5.md` の後継。**v5 の「扉と門を同じ壁に並べる」は、見た瞬間に大きさを比較できてしまう**ので全廃。

## 指摘(そのまま)

> 明らかに大きくなってることがばればれ。出口も大きいし。錯覚がいかせてない。
> 脳がバグる構造にしてくれ。リミナルスペースみたいにしたい。

## 原理

錯覚は「比較する物が無い」時にしか成立しない。だから:

1. **部屋には縮尺 S がある**(0.5 / 1 / 2)。壁・天井・扉・家具・照明・テクスチャの目地まで全部 S 倍。
   中に居る限り、どの部屋も「普通の部屋」にしか見えない。**同じ間取りを縮尺違いで並べる**(リミナルの反復)。
2. **廊下は先細り(強制遠近法)**。部屋 A(縮尺 1)と部屋 B(縮尺 2)を繋ぐ 4m の廊下は、
   A 側の口が 2m 幅、B 側の口が 4m 幅の台形。中を歩くあいだ自分の縮尺も **連続的に** 変わる。
   台形の廊下は頂点について自己相似なので、**歩いても廊下の絵は一切変わらない**。ただの廊下に見える。
3. **縮尺が無い(絶対寸法の)物は 5 つだけ**: 柵 1.7m / 隙間 1.0m / 溝 4.6m / 高い敷居 0.9m / 出口の扉。
   これが謎解きであり、同時に唯一の手がかり。「あの部屋では柵が膝の高さ」「出口が小さく見える」。
4. **音も、目の高さの補間も、光る線も無い**。足音のピッチも変えない。何も起きない。

気づくのは、廊下を抜けて「さっきと同じ部屋」に立ち、柵が膝の高さで出口が小さいと分かった時。
それでも自分が大きくなった実感は無い(絵が一度も変わっていないから)。これが狙いの「脳がバグる」。

## ルール(プレイヤーには見せない)

- 部屋に入った時の縮尺 = その部屋の縮尺。口はすべてその部屋の扉。
- 柵は縮尺 2 でだけ跨げる(登れる高さ 0.9S + 0.25S)。隙間は 0.5 以下でだけ通れる。
  溝は 2 の歩き跳びでだけ届く。高い敷居(0.9m)は 1 以上でだけ登れる = 0.5 の部屋へは一方通行。
- 出口(絶対寸法)は縮尺 2 の部屋では小さく、0.5 では巨大に見える。

## 8 面

| 面 | 何を見せるか |
|---|---|
| 1 同じ部屋 | 廊下の先は同じ部屋。柵が膝の高さで、出口が小さい。窓から「大きい方の部屋」が見えている |
| 2 隙間 | 同じ部屋。今度は隙間が立って通れて、出口が巨大 |
| 3 順番 | 同じ間取りが 3 つ。柵を跨げる写しと隙間をくぐれる写しを順に通る |
| 4 窓 | 同じ部屋が 3 方向に。窓越しに「溝が細く出口が小さい」写しを選ぶ |
| 5 落とし穴 | 高い扉に跳んで入ると降りた先は同じ部屋。扉が高い所にあって戻れない |
| 6 帰り道 | 回っているうちに最初の部屋に戻る(実は縮尺違いの写し) |
| 7 溝 | 大広間の写しでだけ溝が跳べる。奥の高い扉の先は小さな写し |
| 8 一棟 | 同じ間取りが 4 つ。縮尺だけが違う |

## 実装

- `gen_stages.py`: 部屋に `scale`。全モデルは単位寸法で作り transform scale で S 倍(目地も S 倍)。
  照明は位置と range を S 倍、強さはそのまま(エンジンの減衰は range 窓掛けなので k^2 だと白飛びする。実測)。
  廊下は manifest の `tn_*`(Blender の台形メッシュ、模様の無い塗装)+ 8 段の見えない箱の当たり判定。
- `Junction.lua`: 廊下の中で `t/L` から縮尺を線形補間して `pscale` に書く。体(5 種)は口の手前 0.35m で入れ替え、
  廊下の中は小さい方の体。目の高さは `FreeLook.lua` が「体の足元 + 1.7 × pscale」で置く。
- シミュレーションの状態は (部屋, 区画)。大きさは部屋が決める。詰み無し検査あり。
- 実測(第1面): 廊下 z=6.1→10.1 で pscale 1.00→2.00 が連続、体は t=3.68 で 2 へ。着いた部屋の絵は A と同じ。

# v6.1 — 第9面「回廊」: 錯覚・トリック・リミナルを組み合わせる(2026-09-03)

指摘: 「ただモデルの大きさが変わっただけ。比較対象がないし錯覚していない。脳がバグる現象は起きない」。
その通りで、錯覚は【見えている物と知っている事の矛盾】でしか起きない。縮尺の違う部屋を歩くだけでは矛盾が無い。

## 調べた事(ゲームで実装されている「脳がバグる」の型)

| 型 | 実例 | 中身 |
|---|---|---|
| 偽の非ユークリッド | Antichamber / Stanley Parable / Duke3D のトーラス廊下 | 同じ見た目の場所へ黙って転送。廊下が無限に続く、扉を抜けたら出発点、階段を上っても同じ場所 |
| 強制遠近法 | Superliminal / Ames room | 見えている大きさと実寸の矛盾。近づくと違う |
| 変化盲 | P.T. / Layers of Fear | 目を離した隙に扉が消える・道が開く。「空間の確信」を壊す |
| 反復と沈黙 | リミナルホラー全般 | 同じ部屋が続き、何も起きない中で小さな変化が刺さる |
| 不可能構造 | Escher / Monument Valley / Echochrome | 上り続けて元の場所(ペンローズ階段) |

## この面に入れた仕掛け(実機で全部確認)

1. **無限廊下**(型1): 同じ廊下 C1-C2-C3。C2→C3 の扉の中で C1→C2 の扉の中へ黙って転送。3 周で解ける。
   前後の絵(扉の向こうに同じ廊下)が同じなので転送は見えない。振り返ると廊下は 3 本しか無い。
2. **無限スロープ**(型5): 上りのスロープ R1-R2-R3。R2→R3 で R1→R2 へ転送(高さも 3m 戻す)。4 周。
   上り続けたのに、着いた部屋は 9m 上の「最初の部屋の写し」。
3. **来た扉が塞がる / 塞がれていた扉が開く**(型3): 写しの部屋 T で、背を向けている間だけ動かす。
   南の扉は壁になり、東の「壁で埋められた扉枠」が開いている。音も無い。
4. **窓の向こうの自分の部屋**(型4): T の窓から、同じ部屋の 2 倍の写し T2 が見える(柵が低く、出口が小さい)。
5. **先細りの廊下**(型2): T → T2。歩くあいだに縮尺が 1→2。着いた T2 は「普通の部屋」で、柵だけ膝の高さ。
6. **反復**: S / T / T2 は同じ間取り。廊下もスロープも同じ物の連続。

## 実装(v6 に足した物)

- 部屋に `y`(標高)。スロープ `ramp12`(床・天井を傾けた箱、横壁は箱)。廊下 `corr12`。
  これらの壁・床・天井は manifest(`wm_/fm_/cm_`)で Blender が出す。
- `warps=[dict(fromTunnel, toTunnel, loops)]` → Lua が扉の中の面を横切った時に `physics:setPosition` で転送(向きはそのまま)。
- `plugs=[dict(mouth, mode="appear"|"seal", delay)]` → 口を塞ぐ箱。プレイヤーが 2.5〜9m に居て
  背を向けている(視線との内積 < -0.3)時だけ動かす。
- 出口は出口の部屋の標高に置く(9m 上の部屋で床下に埋まっていた)。廊下の `y0` は口の絶対高さ。
- 実測: 廊下ループ z 37.8→25.2(3 回)、スロープループ z 85→72 / y 6.6→3.9(4 回)、
  T で seal→appear、T2 で縮尺 1→2、柵を跨いで CLEAR。
