# JUNCTION v5 — 「継ぎ目」を本物にする(2026-09-02 夜)

`docs/SCALE.md`(v3〜v4.3)の後継。**テレポート・覗き箱・体当たりの継ぎ目は全廃する。**

## 指摘(そのまま)

1. ステージが単調。複数面あっても同じ攻略しかない
2. ギミックは良いが分かりづらく、何が起きているか分からないまま止まる
3. 扉に入ると照明の感じが変わる。「通り抜けた」ではなく「入った」感が強い
4. 途中から出てくる変な物に触れると部屋がワープする。意味が分からない
5. もっと体感で面白い謎解きを

## 診断

3 と 4 は同じ根から出ている。**部屋が 52m 離れた別の箱で、扉が全部テレポートだった。**
覗き箱で「向こうが見える」ふりをしても、照明の配置(部屋は四隅 4 灯・覗き箱は中央 2 灯)、
白い板の灯り、蛍光灯の明滅、全部が扉の前後で入れ替わる。どれだけ絵を合わせても
**光は合わない**。そして「気づいたら大きくなっている」を狙って変化を隠したので、
プレイヤーは**何が起きたか分からない**(指摘 2)。隠すほど分からなくなる。

1 は、面の骨格が全部「大きくなる口を探す → 柵を跨ぐ」「小さくなる口を探す → 隙間をくぐる」
の 2 パターンで、部屋の数と手数を増やしただけだったから。

## v5 の答え: 世界をひと続きにして、継ぎ目を【壁の中のトンネル】にする

> **継ぎ目 = 厚い壁を貫くトンネル。入口と出口の大きさが違う。**
> **中の線を越えると、向こう側の大きさになる。**

- 建物はひと続き。扉をくぐっても**場所は飛ばない**。照明も部屋もそのまま続く。
- 線を越えた瞬間、**世界が目の前で膨らむ／縮む**(0.35 秒)。隠さない。**見せる。**
  自分が変わったのではなく世界が変わったように見えるが、什器との対比で自分だと分かる。
- 往復すれば必ず元に戻る(線の向こう側の大きさになるだけ)。
- **自分より小さい口には物理的に入れない**(トンネルの断面がそのまま当たり判定)。
  赤い影で説明する必要がない。

### ルールは 4 行

1. 壁の中に継ぎ目がある。**入口と出口の大きさが違う**。線を越えると向こう側の大きさになる。
2. 自分より小さい口には入れない。高い口(敷居 0.9m)は跳んで登れる大きさでないと入れない。
3. SPACE で跳ぶ。**大きいほど高く・遠く**跳べる。小さいほど狭い所を抜けられる。
4. 緑の扉に触れたらクリア。落ちても直前の継ぎ目に戻るだけ。失敗も制限時間も無い。

### 継ぎ目は 2 種類

- **通り継ぎ目**: 部屋 A と B の間の 4m の壁を貫く。A 側の口と B 側の口の大きさが違う。
  中の線を越えると向こう側の大きさになる。**線の位置は必ず大きい側**(大きい体が
  小さい断面に食い込まないため。δ = 0.35 × 大きい方 + 0.25)。
- **戻り継ぎ目(U)**: 同じ壁に口が 2 つ並び、壁の中で繋がっている。入った部屋に
  別の大きさで戻ってくる。**部屋を増やさずに大きさを変える装置**。
  ★これが「同じ部屋が急に小さく見える／大きく見える」を一番強く出す。

★**部屋に入った時の大きさ = 入ってきた口の大きさ。** 部屋に門の口が無ければ
その部屋で 2 にはなれない。第7・8面の謎はこれ(「どの口から入るか」を選ぶ)。

# v5.1 (2026-09-02 深夜) — 変化を【隠す】に戻す

指摘: 「身体が大きくなったことがばれたら不思議感がうすれる。脳がバグるゲームを作りたい。
大きくなった時の効果音もいらない。第1面はジャンプすれば普通にゴールできてしまう」。

v5 で「世界が目の前で膨らむ」を見せていたのをやめた。**世界がひと続きなのは変えない**。変えたのは 4 つ。

1. **継ぎ目の中は真っ暗**(内張りは黒、灯りを置かない、光る線も置かない)。部屋の光が口から少し
   差し込むだけで、中程は何も見えない。**大きさはそこで黙って変わる**。
2. **目の高さを補間しない・音を鳴らさない**。足音とジャンプ音のピッチも大きさで変えない(教えてしまう)。
3. 遠近が嘘をつく: 扉の奥に見える小口は「遠くにある普通の扉」に見える。着いてみると普通の部屋で、
   振り返ると来た部屋が巨大(か極小)に見える。**気づくのは向こうに出てから**。
4. 柵を 1.35 → **1.70m**、跳べる高さを 0.9 × s^0.7 → **0.9 × s(線形)**。
   登れる高さ 1 → 1.15 / 2 → 2.30。実機で 1 は跳び続けても越えられず、2 は越えることを確認した。
