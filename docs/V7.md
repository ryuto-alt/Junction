# JUNCTION v7 — 錯覚を「目に見える」ものにする(2026-09-03)

`docs/V6.md` の後継。**v6 は錯覚として成立していなかった。** その理由と直し方。

## 指摘(そのまま)

> ただモデルの大きさが変わっただけじゃない？比較対象がないし、錯覚してるかって言われたら全然してない。
> 同じ廊下とかまじでどうでもいい。退屈。目に見える錯覚がない。
> 明らかに坂道が奥にいってるのがばればれ。坂道いらない。
> 扉どこいった？扉の要素なくね。
> ロッカーとかいすが同じ大きさだから全然錯覚じゃない。
> トリックらしさがまったくない。つなぐってテーマに基づいてない。

## 何が壊れていたか(全部その通りだった)

**v6 は部屋も什器も同じ倍率で拡大していた。** つまり縮尺 2 の部屋の絵は、縮尺 1 の部屋の絵と
**ピクセル単位で同じ**。そこに錯覚が起きる余地は原理的に無い。「比較対象がない」という指摘が
そのまま原因の名前になっている。

同様に:
- 無限廊下は「同じ絵が続く」ので、成功しているほど**何も起きていないように見える**。退屈で正しい。
- 上りの坂道は、床の傾きと天井の高さが動くので**転送が絵に出る**。ばれて当然。
- 開口は壁の穴でしかなく、扉のモデルが 1 枚も無かった。
- テーマ「つなぐ」の主語(扉)が消えていた。

## v7 の原則: **比較対象を、部屋の中に置く**

錯覚は「知っている大きさの物」と「見えている大きさ」が食い違った時にしか起きない。

1. ★**什器は絶対寸法**。ベンチ 0.95m、ロッカー 1.95m、木箱 0.75m は世界のどこでも同じ大きさ。
   部屋(壁・天井・扉・目地)だけが縮尺を持つ。
   - 縮尺 0.5 の部屋 → 自分は 0.9m。**ロッカーは自分の 2 倍の壁になり、ベンチが目の高さ**。
   - 縮尺 2 の部屋 → 自分は 3.6m。**ベンチは脛、ロッカーは腰、木箱は靴**。
   これは絵として一目で見える。数字も音も要らない。
2. ★**同じ柵を 2 回見せる**。柵 1.7m は縮尺 1 の部屋では絶対に越えられない壁。
   縮尺 2 の部屋では膝の高さで転がっている。**同じ物が違って見える**のが錯覚の定義。
3. ★**偽の廊下(強制遠近法)**。奥行き 2.5m の箱を、20m の廊下に見えるよう先細りにする。
   天井の照明も同じ比で縮めて等間隔に並べるので、入口からは本物と区別がつかない。
   突き当りには 25cm の緑の扉。2 歩で手が届き、**嘘が目の前で崩れる**(Superliminal)。
4. ★**背後改変**。プレイヤーが部屋に背を向けている間だけ、部屋そのものを書き換える。
   家具の位置、光の色、そして**壁だった所に扉が開く / 来た扉が壁になる**(P.T.)。
5. **坂道は全廃。無限廊下も外した。** どちらも「歩いても何も起きない」ので退屈だった。
6. **扉板のモデルを足した**(`doorleaf.gltf`)。70 度開いた板とハンドル。開口が扉に見える。

## 実装

- `gen_stages.py`
  - 什器は `scale=(1,1,1)`(柱だけ天井高に合わせて Y のみ伸ばす)。`fixtures` の半径・天端も絶対値。
  - `FAKE(id, room, wall, off, depth, look)` … 偽の廊下。`frustum(..., L=depth, solid=True)` +
    縮めた照明 + 突き当りの小さな出口。**シミュレーションの経路には入れない**(`links` に無い口は無視)。
  - `MORPH(id, room, at, r, delay, org, alt, seal, unseal, light)` … 背後改変。
    `org`/`alt` の什器を `MorphA_*`/`MorphB_*` として両方置き、Lua が Y を入れ替える。
    `seal`/`unseal` は栓(`Plug_*`)を自動生成する。
  - 扉板は開口ごとに 70 度開いた姿勢で配置。角度はモデルの局所 +X が `right(yaw)` である事から逆算。
  - 照明は `intensity * min(1,k)^0.8`(小さい部屋が白飛びした)。range は k 倍。
- `blender_kit.py`
  - 廊下メッシュ `tn_*` に**床=カーペット / 天井=天井板 / 壁=塗装**を割り、UV を実寸から出す。
    白い筒に見えていたのを直した。偽の廊下もこれで作る。
  - `doorleaf.gltf` … 蝶番原点の扉板。框・鏡板・ハンドル・錠前。
- `Junction.lua`
  - `morphs` … 「トリガ点から半径 r 以内」かつ「部屋の中心が背中側(内積 < -0.2)」が `delay` 秒続いたら発火。
    偽の廊下の突き当りを見ている間は、部屋が視界に入らないので必ず気づかれない。

## ★実測で潰した罠

- ★★**`frustum` の当たり判定で区間長を `L` という名前にすると、外側の `L`(廊下の全長)を潰す。**
  2 個目以降の判定箱が全部入口に折り重なり、**扉に入れなくなる**。変数名は `seg`。
- ★**廊下の天井は床と逆回りに並べる。** 同じ回りだと裏面になって真っ黒になる。
- ★扉板の角度は `wallYaw + 定数` では出ない。`atan2` で逆算する(初回は板が廊下の中に倒れていた)。
- 縮尺 0.5 の部屋は照明が白飛びする。強さを `min(1,k)^0.8` 倍に落とす。
