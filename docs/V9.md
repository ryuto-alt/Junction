## 1. ★「部屋と部屋の間の白い壁」の真犯人 — 廊下メッシュの突き当り

**犯人は照明でも寸法でもなく、台形メッシュが必ず持っていた【突き当りの壁】1 枚だった。**

`blender_kit.py: build_manifest` の廊下メッシュは、床・天井・左右の壁に加えて
**奥の壁**を無条件で張っていた。これは偽の廊下(強制遠近法)の落ちに要る面で、
コメントにも「実物の廊下では部屋の壁に隠れて見えない」と書いてあった。**隠れていない。**

廊下の奥の端は、向こうの部屋の壁の開口と**ぴったり同じ位置・同じ寸法**にある。
つまりその 1 枚は、向こうの部屋の入口を**過不足なく塞ぐ白い板**だった。

| | v8(実測) | v9 |
|---|---|---|
| 見た目 | 扉を開けると 4m 先が白い壁。奥に部屋があると分からない | 床・天井・什器・柵まで、向こうの部屋がそのまま見える |
| 当たり判定 | **無い**(板は絵だけ)。歩くと white wall をすり抜ける | — |
| 窓 | 同じ板が入るので**窓が不透明**。「窓は物差し」の第2面が成立していなかった | 向こうの部屋が見える |

→ `frustum(..., cap=)` を足し、`cap` はマニフェストの spec に載せて
**偽の廊下のときだけ**奥の壁を張る。spec が変わるのでモデル名(ハッシュ)も変わる = 全廊下が作り直される。

★この事故が 8 面ぜんぶで起きていたので、**v8 の「窓」「三つの廊下」「輪」は
設計どおりに見えたことが一度も無かった。**

## 2. ★「坂道でがくんと視点が跳ねる」の真犯人 — 8 段の階段だった当たり判定

坂になっていたのは**偽の廊下**。強制遠近法は口を中心に相似で縮めるので、
**床が必ず上がる**(v8: 奥行 2.5m で 1.14m = 24.5 度)。ここまでは設計どおり。

問題は当たり判定で、廊下を **8 個の軸並行な箱に刻んで**いた。傾いた床を 8 分割すれば
**1 段 0.14m の階段**になる。`CharacterController` の段差登り(stepHeight 0.25)が
そのつど体を持ち上げるので、3m 歩く間に**視点が 8 回跳ねる**。

床も天井も側壁も**平面**なので、傾けた板 1 枚ずつで厳密に置き換えられる。

```
床   : 進行方向に dy 上がる板 1 枚(X または Z 回りに傾ける)
天井 : 同上
側壁 : すぼまる向きへ Y 回りに寝かせた板 1 枚 x 2
```

★回転の符号は `build_room` のスロープ床と同じ規約(右手系: +X 回りは +Z を下へ、+Z 回りは +X を上へ)。
**実測で確かめた**(物理レイを 0.15m 刻みで撃つ): 床の高さが 0.0683/0.15m で完全に線形 = 段差ゼロ。

さらに 2 つ直した:

- **廊下の中で体を入れ替えるときの押し込み(`placeT`)を 0 に。** v8 は 0.05 秒入れていたが、
  押し込み中は**廊下の走査そのものが飛ばされる**ガードがあるため `inTunnel` が false に落ち、
  `shownScale` が体の縮尺へ飛ぶ = **目の高さが一瞬跳ねる**。廊下の中では 1 回置けば足りる。
- **偽の廊下を 2.5m/20m → 3.2m/16m に。** 縮み率 0.125 → 0.2、坂が 24.5 度 → 18 度。
  嘘の強さはほとんど変わらないのに、登る感じがだいぶ減る。

## 4. 1〜3 面 — 「小さくなったのか、目が騙されているのか」

### 4-1. 什器の座標を引き直した(`SET1`)

v8 の `SET` はロッカーが (5.4, 2.6)。ここは**東壁の窓の真正面 0.6m** で、窓越しの部屋を隠す。
さらに柵を z 軸へ回すと、どの位置でも `check_footholds` が落ちる(踏み台になる)。

`SET1 = ロッカー(4.6, 4.6) / ベンチ(1.8, -1.0) / 木箱(3.6, -4.4)` は次を全部満たす:

- 全部 x ≥ 1.8(単位)。柵を x=-2.5 に置いても「柵から 3m + 半径」より遠い
- 東西の壁の口の助走(2.5 x 縮尺)を潰さない
- 窓(中心 z=+1.6 / 幅 3.6)の正面に何も無い

★4〜8 面は v8 のまま(`SET`)。物差しは**1 つの面の中で**揃っていればいい。

物差しの効き方(生成時に計算した実値):

| 縮尺 | 自分の目 | ベンチ 0.95m | ロッカー 1.95m | 柵 1.70m |
|---|---|---|---|---|
| 0.5 | 0.85m | **目の高さの 112%** | 目の 2.29 倍 | 越えられない |
| 1 | 1.70m | 目の 56%(腰) | 目の 1.15 倍 | 越えられない |
| 2 | 3.40m | 目の 28%(脛) | 目の 0.57 倍(腰) | **跨げる** |

### 4-2. 見えるのに行けない門(`decoys`)

当たり判定も判定用の印も持たない、**ただの絵の門**。柵や隙間の向こうに置く。
「出口はもう見えている。届かないのは自分の大きさのせいだ」を無言で言う装置で、
1〜3 面はこれを軸に組んである。

★**目の高さと関門の高さの関係を必ず計算すること。** 第3面の餌は当初、隙間(1.0m)の
**4m 先**に置いていた。目の高さ 3.4m から 1.0m の隙間ごしに見えるのは
「隙間の上端を通る視線より下」だけなので、16m 手前から見て 4m 先は y=0.4m までしか見えない
= **緑が一切見えない**。2.5m 先に寄せて、門の光る敷居が覗くようにした。

### 4-3. 三つの面

| 面 | 題 | 新しく教える事 | 縮尺の道筋 | 最短 |
|---|---|---|---|---|
| 1 | おなじ部屋 | **部屋を 1 つしか使わない**。同じ部屋に四度帰ってくる | 1 → 0.5 → 1 → 2 | 3 |
| 2 | 輪 | **戻ってきた部屋が、戻ってきていない** | 1 → 0.5 → 1 → 2 | 3 |
| 3 | 並び | **歩いても絵が変わらない**(部屋 3 つが 1 本の廊下に見える) | 2 → 1 → 0.5 | 2 |

**第1面「おなじ部屋」** ★この面は**部屋を 1 つしか使わない**。
A / B / C / D は間取りも什器の座標も柵の位置も門の位置も、東の偽の廊下まで**完全に同じ**。
違うのは縮尺(1 → 0.5 → 1 → 2)だけ。

★**「進んだのか戻ったのか分からなくする」仕掛け:**
部屋に入った時点で、北の扉は**塗り潰されている**(栓 `mode="appear"`)。つまりどの部屋も、
入った瞬間は**出口の無い閉じた部屋**に見える。西の柵まで歩いて門を見る(= 部屋の中心が背中に来る)と、
背後で北の扉が開き、同時に**来た南の扉が塞がる**(扉板ごと消える)。振り返ると、そこは
**最初の部屋と寸分違わない部屋**になっている。北へ突っ切って見通せないので、部屋が 4 つある
ことに気づけない。

★**伏線は「柵の向こうの緑の門」**。門は縮尺を持たない絶対寸法なので、部屋に入るたびに
大きさが変わる。変わっているのは門ではなく**自分**なのだが、部屋が同じなのでそう見えない。
毎回かならず柵の前まで歩かされるので、四度とも同じ門を、違う大きさで見ることになる。

| | 自分の目 | ベンチ 0.95m | 柵 1.7m | 門(高さ 2.9m) |
|---|---|---|---|---|
| A(x1) | 1.70m | 腰(目の 56%) | ちょうど目の高さ。門の上半分だけ見える | 見上げる |
| B(x0.5) | 0.85m | **目の高さ(112%)** | 背丈の倍の壁 | **天井まで届く** |
| C(x1) | 1.70m | 腰 | **A と寸分違わない** | A と同じ |
| D(x2) | 3.40m | 脛(目の 28%) | **膝。跨げる** | 小さい。跨いだ先にある |

★**口は壁の真ん中(off=0)にしか置けない。** 世界座標の off は繋がる 2 部屋で共有されるので、
「全部の部屋で単位座標の口の位置を揃える」と連立させると off=0 以外に解が無い
(x0.5 / x1 / x2 を混ぜる限り)。だから北へ真っ直ぐ歩くと門を見ずに通過できてしまう。
栓で閉じたのはそのため ── 見た目のためではなく、**動線を強制するため**。

**第2面「輪」** A(x1) → B(x0.5) → C(x1) → D(x2)。
★**A と D は間取りも家具の座標も柵も門の位置も完全に同じ。違うのは縮尺だけ。**
一周して D には A と同じ「南から入って北を向く」構図で出るので、最初の部屋の見え方そのもの。
違うのは家具が小さいことだけ。振り返ると来た扉は消えていて(morph)、
東の壁には A と同じ位置に扉が「ある」が、それは偽の廊下 ── 戻ろうとすると嘘だと分かる。
C でも柵の向こうに門が見えていて、**二度焦らしてから三度目で跨がせる。**

**第3面「並び」** A(x2) → B(x1) → C(x0.5) を一直線に並べ、扉を全部 off=0 で揃える。
★始まりの部屋から北を見ると、だんだん小さくなる 3 つの戸口が**1 本の長い廊下**に見える。
歩くと継ぎ目ごとに自分も半分になるので、**絵はいつまでも同じ = 進んでいる気がしない。**
B の北の口は敷居 0.9m(x1 なら登れて x0.5 では登れない = **入ったら戻れない**)。
B の東は餌の部屋 D(x2)で、1.0m の隙間の向こうに門が見えているが 3.6m の体では入れない。
「小さくならないと通れない」と分かってから、一方通行の敷居を越える覚悟をさせる。

## 5. 部屋を並べるときの規約(v9 で足した検査が守らせる)

- **4 部屋の輪は、向かい合う部屋の縮尺が等しくないと閉じない。**
  east→north と north→east で同じ場所に着く条件は `hx_A + hx_B = hx_D + hx_C` かつ
  `hz_B + hz_C = hz_A + hz_D`。box12 だけで組むと `k_A = k_C` かつ `k_B = k_D` に落ちる。
  → v9 の第2面は輪を閉じず、**同じ絵の部屋をもう 1 つ置いて輪だと思わせる**方を取った。
- `check_layout` … 部屋どうしの重なり。
- `check_corridors` … 廊下(継ぎ目・偽の廊下)が関係ない部屋を貫いていないか。
- 既存の `check_solvable` / `check_no_deadend` / `check_fakes` / `check_runup` / `check_footholds` / `check_cine` はそのまま。
