# stagedemo3 / 見たものが、そうなる（リミナル版・2026-09-05）

前版（v14「つながった世界」）への指摘を全部つぶして作り直した版。**シーンもスクリプトも全て生成物**で、
`source/gen_liminal.py` を実行すれば同じものが出る。手でシーンを触らない。

## 何を直したか（指摘 → 対応）

| 指摘 | 対応 |
|---|---|
| いちいちトグル（E）を押さないと、つながりが見えない | **キーを廃止**。破片は「その位置から見て重なった」瞬間に実体化する。合い具合は連続量なので、近づくほど**継ぎ目の光・音の高さ・中央の環**が育つ。押す物は無い |
| 視点から見えた重なりがオブジェクト化される思考は良い | それ**だけ**にした。4 つの継ぎ目すべてが同じ 1 つの規則（下の数式）で動く。別ジャンルの仕掛けを混ぜない |
| 文字が余計に多い | 画面の文字は **開始 9 秒の操作案内 1 行** と **クリア時の 1 語** だけ。章タイトル・ヒント・キー一覧は全部消した。案内は「非常口の緑」「明るさの差」「床の擦れ跡」でやる |
| モデルがリミナルっぽくない | 黄ばんだ壁紙・芥子色の絨毯・落とし天井・埋め込み蛍光灯（点いているのは飛び飛び）・開かない扉が並ぶ廊下・水の抜けたプール室。テクスチャは全部生成（`gen_liminal_tex.py`） |

## 仕掛け（1 つだけ）

焦点 **F**（目の高さ 1.70m の 1 点）から見たとき、破片は本物と**完全に同じ形に重なる**ように置いてある。
置き方は F 中心の相似変換 1 本:

```
P' = F + k (P - F) ,  scale' = k · scale        (0 < k ≤ 1)
```

ずれの尺度は「対応点への視線の角度差の最大値（度）」。F に立つと 0 になり、離れるほど増える。

* `lock` 度未満を **0.28 秒** 保ち、かつ継ぎ目の中心が視野 26° 以内にあれば確定
* `warn` 度から予兆（環が満ち始める・継ぎ目が光り始める・ドローンの音程が上がる）
* 確定すると破片は k → 1 へ 0.85 秒で吸い寄せられ、**そこで初めて当たり判定が付く**
  （未確定の破片は素通りできる ＝「まだ実体ではない」が触っても分かる）

**幾何の性質（設計上の重要事項）**: 角度差は視線に対して**横方向に敏感・奥行きに鈍感**。
1 点というより「F を通る 1 本の線」の上が正解になる。だから確定域は「細長い帯」になり、
プレイヤーの仕事は**左右の立ち位置を合わせること**になる。これを踏まえて焦点は
**廊下の中心から少し外して**置いてある（中心に置くと真っ直ぐ歩くだけで勝手に解ける）。

## 順路（4 つの継ぎ目）

| # | 場所 | 破片 | 焦点 | 確定域 | 結果 |
|---|---|---|---|---|---|
| 1 | 入口の廊下 | 扉枠の左半分（k=0.42） | (-0.52, 6.3) | 0.40 m² | 枠が閉じ、壁が床下へ沈んで戸口になる |
| 2 | 事務室（床が抜けている） | 通路の 3 片（k=0.72/0.53/0.40） | (-6.3, 18.3) | 1.42 m² | 斜めの橋がつながり、穴を渡れる |
| 3 | タイル室（水の無いプール） | 階段の 3 群（k=0.62/0.46/0.36） | (-5.4, 53.6) | 0.97 m² | 12 段の階段が組み上がり、高い扉へ登れる |
| 4 | 上階の廊下 | 枠の左右と扉板（k=0.55/0.35/0.72） | (5.55, 69.2) | 0.99 m² | 非常口が灯り、扉が開いて白い部屋へ |

第 1 と第 4 は同じ廊下の造り（同じ幅・同じ灯り・同じベンチ）。**同じ場所に戻ってきた気持ち悪さ**が狙い。
第 4 の焦点も第 1 と同じ「中心から少し左」＝最初に覚えた事をそのまま使わせる。

## 作り方

```
"C:/Program Files/Blender Foundation/Blender 5.2/5.2/python/bin/python.exe" source/gen_liminal_tex.py  # tex/lm_*.png（numpy が要る）
"C:/Program Files/Blender Foundation/Blender 5.2/5.2/python/bin/python.exe" source/gen_liminal_sfx.py  # audio/lm/*.wav
python source/gen_liminal.py       # scenes/stagedemo3.json と components/Liminal.lua（標準ライブラリだけ）
python source/sim_liminal.py       # 机上シミュレーション。PASS しないならエディタで開かない
```

* **Blender は要らない**。全部「テクスチャを貼った箱プリミティブ + uvTiling」で組んである。
  反復が速く、glTF の書き出し事故（texCoord:-1 でモデルごと落ちる等）も起きない。
* 動作の編集元は `source/liminal_runtime.lua`。`assets/components/Liminal.lua` は
  `-- >>>DATA` 〜 `-- <<<DATA` に継ぎ目のデータを差し込んだ**複製**なので直接触らない。
* テクスチャを描き直したら **`dx12_reload_assets {force:true}`**（エンジンはパス単位で一生キャッシュする）。

## 机上シミュレーション（`sim_liminal.py`）

エンジンを起動せずに次を検査する。**ここを通らないものは開かない**。

1. **破片の干渉** — ずれた状態の 49 個が壁・床にめり込んでいないか、破片どうしが重なっていないか
2. **順路の通し歩き** — 当たり判定だけの BFS（段差 0.32 / 頭上 1.8 / 体半径 0.34、**同じ升でも高さが違えば別状態**）。
   継ぎ目を 1 つずつ確定させながら出口まで行けるか、**かつ確定前は行けないか**
3. **確定域の広さ** — 焦点の周り 8m 角を 15cm 刻みで走査。狭すぎ（< 0.10 m²）も広すぎ（> 1.60 m²）も落とす
4. **足場の連続性** — 階段の蹴上げ 0.283m（上限 0.32）、踊り場との段差、橋の天端が床と面一か
5. **照明** — 順路上の 15 点に灯が届いているか

最終結果（2026-09-05）: **PASS**。確定域 0.40 / 1.42 / 0.97 / 0.99 m²、蹴上げ 12 段すべて 0.32m 以下。

## 実機テスト（MCP、2026-09-05）

`lm_auto=1` + `lm_gx/lm_gz`（目的地）で歩かせる検証フックを Lua に入れてある（Play のたびに自動で切れる）。

* **通し**: 開始 →(歩く)→ 継ぎ目1 確定 → 戸口をくぐる → 事務室 → 継ぎ目2 確定 → 橋を渡る（落下なし）→
  タイル室 → プールを回り込む → 継ぎ目3 確定 → 階段を登る（y 0.90→4.30）→ 上階 → 継ぎ目4 確定 →
  扉が開く → 白い部屋 → `lm_clear=1`。**キーは移動だけ。確定操作は 1 度も無い**
* **誤爆しないこと**: 廊下の中心（x=0）を真っ直ぐ歩くと継ぎ目1 は a=0.69 まで育つが**確定しない**（誤差 3.76° > lock 1.6°）
* **見ていないと確定しない**: 継ぎ目2 の焦点に立っても、橋に顔を向けるまで確定しない（視野 26° の判定）
* **落下復帰**: 穴に落ちると直前の到達点へ戻る。確定済みの継ぎ目は保たれる
* scriptErrors 0 / `dx12_validate_scene` PASS / `dx12_ui_audit` strict 100点 A・警告 0
* 性能: 137fps（144 上限）、GPU 0.61ms、draw 571、点光源 25、三角形 6.8k

## 踏んだ罠（次に触る時に効く）

* ★**同じ場所に壁を 2 枚建てない**。廊下 A の突き当りと事務室の手前壁を別々に建てていて、
  同一平面で z ファイティング → 見る位置で壁の色が入れ替わった。**壁は 1 枚で両方の部屋の面を兼ねる**。
  床でも同じ（連絡通路の床が室の床と 0.3m 重なっていた）。
* ★**継ぎ目の光は「まわりより明るい」ことが仕事**。power 0.5 だと壁より暗く、**暗い線**に見えて逆効果。
  1.25 を基準にして、合ってくると 5.6 まで上げる（bloomThreshold 1.05 に乗る）。
* ★**扉枠を「方立 + 楣」だけにすると、ただの白い棒 2 本にしか見えない**。沓摺を足して
  **閉じた長方形**にした瞬間に「扉枠の片割れ」だと読めるようになった。
* ★**塞ぎ板は床下へ沈める**。奥へ押すと白い部屋の中に立って景色を塞ぐ（実際にやって気付いた）。
* ★**装飾の扉を深く彫り込むと真っ黒な穴に見える**（見込み 0.10 → 0.045 で解決）。
* ★**点光源には影が無いので壁を透ける**。白い部屋の灯りが廊下側の枠を照らしていた。range を絞る。
* ★**UI の文字は alpha 0 でも縁取りが残る**＝消えたはずの案内が黒い文字で出続ける。
  `setUiVisible(false)` で要素ごと消すこと。
* ★**終わりに露出を上げっぱなしにすると UI もポストを浴びて文字が飛ぶ**。閃光 → 落ち着く、の 2 段にして
  文字は落ち着いてから出す。
* ★**BFS で「またげる高さ以下の物」を壁扱いすると、階段が一段も登れない**（シミュレータ側の罠。
  `blocked()` は `top <= h + stepHeight` を必ず素通りさせる）。同じ升を高さ違いで再訪できないと
  **階段の下に床があるだけで登れなくなる**（先に床側で升が埋まる）。
* ★**最上段と踊り場の間を 0.2m 空けると詰む**。「登れるのに入れない」という一番たちの悪い形。
  シミュレータの通し歩きで捕まえた。
* ★**MCP の検証フックは Play のたびに落とす**。`lm_auto` が残ったままだと人が遊んだ時に勝手に歩く。
