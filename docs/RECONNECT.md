# JUNCTION / RECONNECT

2026-09-05。実装済みの3室・4接続のステージ。起動シーンは `scenes/reconnect.json`。

## 体験の中心

**離れているのに、つながって見える。その見え方を、現実にする。**

プレイヤーが床の金色のレールに沿って歩くと、奥行きの違う足場の端が重なっていく。継ぎ目が淡い緑に変わり、Eを押すと道が確定する。各片が観測点から伸びる同じ視線上を動くので、正解の視点では輪郭が変わらないのに、横へ動くと足場の奥行きが変わったと分かる。

元の版では、見る・見ない・首を振る・残効を待つと操作と成功理由が切り替わっていた。今回は「立つ場所を変える、線をつなぐ、道を歩く」を全室で共通にする。

## 順路

| 空間 | 見せるもの | プレイヤーの発見 | 接続後 |
| --- | --- | --- | --- |
| 01 切れた線 | 10mの溝と、深さの違う4枚の足場。床に足形と観測レール | 横へ歩くと継ぎ目がそろう | 一本の橋になる。初めての成功を渡って確かめる |
| 02 角の向こう | 5本の桁でできた、奥行きがばらばらの折れ曲がった道 | 正面だけでなく、左から見ることで複数の角が同時につながる | 4つの角を曲がって対岸へ。向きを変えるほど奥行きの変化が分かる |
| 03 空中の踊り場・前半 | 手前の断片、その先の小さな島、さらに上階の出口 | 全部を同じ位置からつなぐ必要はない | 最初の橋を渡って、島に新しい観測点を得る |
| 03 空中の踊り場・後半 | 島から見ると重なる、宙に浮いた上り道 | 前の接続が次の接続の立ち位置を作る | 高さ3.2mの出口まで坂を歩く。4接続で扉が開く |

学ぶことは「横への視差」、発展は「曲がった形」、応用は「次の視点そのものをつなぐ」。時間制限は設けない。

## 入力とフィードバック

- WASD：歩く。Shift：少し速く歩く。マウス：見る。矢印キーでも視点操作可。
- E：継ぎ目がそろっているときに接続を確定。自動で勝手に解けない。
- R：直前の安全な足場へ戻る。接続した道は保持する。
- ESC：マウス捕捉の切替。クリア後のENTER：新規にやり直す。
- 金色：未接続。継ぎ目の淡い緑と小さな音：接続可能。道の緑色：接続済み。
- 画面中央にメーターは置かない。左下の短文は操作と理由を伝える。実際の接続は3Dの線と音で見せる。

## 実装の要点

観測点をE、完成した道の頂点をV、断片ごとの係数をkとすると、未接続の頂点は `E + k(V-E)`。0.85秒でkを1へ補間して接続する。この相似変換により、理想観測点からの投影方向は補間中も一定になる。

判定は指定座標への進入ではなく、すべての対になる継ぎ目が作る視線の最大角度差。許容角1.8度。さらに接地・順路・前方視野を確認する。カメラの向きだけで視差の誤差は消えない。

断片は生成時からシーンに置く。未接続の衝突面は地下へ退避。接続アニメーションの完了時に独立したKINEMATIC衝突面を完成位置へ置く。アニメーション中だけ歩行を止め、衝突面の急変でプレイヤーを押し出さない。

キャラクター中心は地上0.9m、眼は中心+0.8m。復帰はCharacterControllerに対応した `physics:setPosition` を使う。3室目の島もチェックポイントになる。

`ReconnectInk.hlsl` は実体のガイド線用の静的な色シェーダー。画面の点滅や残像効果に攻略を依存させない。色は頂点色ではなくshaderParamsへ渡す（エンジンのプリミティブの頂点色は白）。

## ファイル

- `source/gen_reconnect.py`：配置・接続定義の生成元。
- `source/reconnect_runtime.lua`：入力、視差判定、接続、衝突、復帰、クリア。
- `source/reconnect_geometry.json`：生成した接続定義。検証・再利用用。
- `assets/components/Reconnect.lua`：定義とランタイムをまとめた生成物。直接編集せず生成元を編集する。
- `assets/scenes/reconnect.json`：379エンティティのシーン。
- `assets/shaders/ReconnectInk.hlsl`：ガイド線。

`python source/gen_reconnect.py` でシーンとLuaを再生成する。旧ジェネレータからは独立しており、旧版の未コミット変更を上書きしない。旧シーンとスクリプトは残してある。

## 実機検証

DX12 MCPを使用。MCPが応答しなかった原因は、旧Node中継プロセスが単一クライアント接続を占有していたこと。エンジンを終了せず、旧中継だけを解除し、pingが成功した。

- Scene validator：PASS、379 entities、1 script。
- Lua実行エラー：0。
- UI strict audit：PASS、100点、警告0。
- 開始位置でEを押しても接続されない。
- 全4接続を実際のE入力で確定。
- 橋、4つの角、中央の島、高さ3.2mの坂、出口をWASD入力で通過。
- 接続されていない道は歩けず落下する。復帰後に接続済みの状態を保持。
- 島でRを押すと島へ戻る。背を向けてEを押しても接続されない。
- ゴール座標付近で `reconnect_complete=1`、クリアログを記録。

通し試験ではMCP入力の再現性のためカメラの向きだけをテスト用設定で固定した。通常プレイでは無効。これは動作と到達可能性の検証であり、初見プレイヤーの理解時間や面白さの評価はまだ行っていない。
